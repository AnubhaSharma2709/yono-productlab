# YONO ProductLab — Business Questions

## 1. Onboarding and Activation

1. How many users start onboarding?
2. What percentage complete onboarding?
3. What percentage of new users reach the activation event?
4. At which onboarding step is the largest drop-off observed?
5. Does activation differ by acquisition channel or device type?

## 2. Feature Adoption

1. Which banking features are used most frequently?
2. What percentage of active users use bill payments, fund transfers and account services?
3. How many users try a feature for the first time?
4. Which features have high initial usage but low repeat usage?
5. How does feature adoption differ across customer segments?

## 3. Engagement and Retention

1. How many daily, weekly and monthly active users are observed?
2. What percentage of users return after their first qualifying activity?
3. How does retention differ across signup cohorts?
4. How frequently do active users return to the application?
5. Which acquisition channels have the strongest observed retention?

## 4. Transaction Journey

1. How many users initiate a simulated transaction?
2. What percentage of initiated transactions succeed?
3. How frequently do transactions fail or get abandoned?
4. Which transaction types have the highest failure rates?
5. Do transaction outcomes differ by device, time period or app version?

## 5. Product Recommendations

1. Which journey should the product team investigate first?
2. Which user segments may need additional onboarding support?
3. Which features warrant further usability investigation?
4. What experiment could validate a proposed product improvement?
5. What additional data would be needed to estimate the impact of the change?

## Analytical Principles

- Define each metric before calculating it.
- Specify the denominator and time window for every rate.
- Distinguish users, sessions, events and transactions.
- Validate data quality before interpreting results.
- Separate observed patterns from causal explanations.
- Do not claim that a product change improves outcomes without appropriate experimental evidence.
- All findings from this project must be labelled as findings from synthetic data.
